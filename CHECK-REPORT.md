## Исправления

| Ошибка исходного кода | Исправление |
|---|---|
| Прокрутка барабана меняла состояние до вызова пересчёта; обработчик мог не сработать | Разделены визуальный выбор и фиксация значения, после остановки запускается пересчёт |
| Барабаны внутри скрытых разделов открывались с неправильным положением | Положение восстанавливается при показе раздела; выбор фиксируется перед добавлением и сохранением |
| Барабаны не управлялись с клавиатуры | Стрелки, Home/End, подписи и состояние выбора для средств доступности |
| Отрицательные значения проходили проверку; ограничения HTML обходились обычной кнопкой | Проверяются конечные положительные числа, границы, график, валюта и период |
| Итог текущего расчёта пропускал позиции без доступного курса | Неполный итог обозначается как недоступный; сохранение такого нового расчёта заблокировано |
| В проектах рубли, доллары и другие валюты просто складывались в одну сумму | Суммы показаны отдельно по каждой валюте без выдуманного общего курса |
| Общие рабочие дни/месяцы проекта вычислялись по графику первой записи | Время каждой записи переводится по её собственному графику и затем суммируется; пояснение есть в проекте |
| Исторический расчёт без курса мог использовать сегодняшний курс | Используется только сохранённый снимок; при отсутствии курса показывается ограничение |
| Поздний ответ сервиса валют мог записать курс для уже изменённого профиля | Проверяются валюта ответа и номер запроса; старый ответ игнорируется |
| Ответ сервиса не проверялся полностью, не было тайм-аута | Проверяются HTTP-статус, базовая валюта, положительные курсы и даты; тайм-аут 10 секунд |
| Сбой сети мог оставлять несоответствующий курс | Кэш используется только для своей базовой валюты, возраст кэша обозначается |
| Текущий расчёт исчезал после обновления страницы | Добавлено сохранение позиций и выбранной единицы в черновик |
| Ошибка записи в браузер останавливала действие без понятного сообщения | Ошибка явно показывается; успешное сохранение не объявляется при отказе |
| Некорректные записи могли ломать список | Доступные записи показываются, исходный повреждённый список защищён от перезаписи |
| Список молча обрезался до 100 расчётов / 50 проектов | Убрана автоматическая потеря старых записей; физическая квота браузера остаётся |
| Старые записи без дохода/курса переносились с сегодняшними данными | Автоматическая недостоверная переоценка остановлена; оригинал остаётся, появляется объяснение |
| Малые положительные расходы отображались как нулевое время | Отображается «< 0,01 ч» / «< 1 мин» и соответствующая минимальная единица |
| В профиле не был указан период дохода; неверные окончания у 21/22 позиций | Период добавлен в подпись, склонение исправлено |
| Модальное окно не ограничивало фокус и не поддерживало Escape | Добавлены роль диалога, фокус, возврат фокуса, Tab и Escape |

Ранняя версия дополнительно имела несогласованные единицы «мин» + «часов работы», ограничения цены целыми числами и дохода шагом 100, отсутствие защиты записи профиля и зависимость от точного расположения файлов. Итоговый пакет использует полную реализацию с явными единицами и согласованными путями. Имена продукта, разделов и существующих кнопок сохранены.

## Проверки

**39 автоматических проверок пройдены.**

Прогон выполнен в Node.js с jsdom: реальные HTML и JavaScript загружаются вместе; имитируются события элементов страницы, хранилище, ответы сервиса валют и ошибки сети. Это проверка логики и DOM, а не полноценный браузерный рендеринг. Для проверки барабанов смоделированы видимость и позиции прокрутки; инерция пальца не моделируется.

Покрытие: пути ресурсов и уникальность идентификаторов, периоды дохода, все единицы времени, пересчёт валют, границы ввода, безопасность вывода названия, прокрутка и клавиатура, сохранение и объединение, переименование и удаление, отмена удаления, восстановление, смешанные валюты/графики, отсутствующие курсы, прежние лимиты списков, повреждённые данные, отказ хранилища, перенос раннего профиля, старые записи, работа без сети, устаревший кэш, некорректный ответ сервиса, гонка ответов при смене валюты.

Полный список результатов — verification/results.json. В verification/test.cjs сохранён повторяемый тестовый прогон; зависимости нужны только для проверки, не для самого приложения.

Контрольный расчёт:
- Рабочих часов в месяц: 5 × 8 × 52 / 12 = 173,333333…
- Доход 150000 ₽ в месяц: 865,384615… ₽/час.
- Покупка 60000 ₽: 69,333333… часа = 8,666666… рабочего дня = 0,4 рабочего месяца.
- Тестовый валютный курс: 1 ₽ = 0,01 USD. Цена 100 USD × 2 = 20000 ₽. Это искусственный курс теста, не текущая котировка.

## Что ещё не подтверждено

- Браузер отклонил открытие локального приложения (`ERR_BLOCKED_BY_CLIENT`). Визуальная вёрстка, реальные жесты iPhone/Android, поведение экранной клавиатуры и Safari не проверены. В CSS внесены защитные правки для узких экранов, но это не заменяет проверку на устройствах.
- Доступность живого сервиса курсов из России и через конкретное соединение пользователя не установлена. Сетевые сценарии проверены подставными ответами. Расчёт в валюте дохода не нуждается в курсе.
- Публикация на существующий сайт не выполнялась: подготовлен готовый пакет для замены.
- Не гарантируется отсутствие любых возможных ошибок. Исправлены выявленные дефекты приложенного кода в пределах указанного тестового покрытия.

Формула исходного приложения сохранена: 52 недели / 12 месяцев, без отдельного учёта отпусков и праздников. История хранится локально в браузере; серверная синхронизация не добавлялась.
