MY RATE 3.0 — ОТЧЁТ О ПРОВЕРКАХ
Дата: 12 сентября 2026

Среда: Node.js 24.19.0, jsdom 30.0.1.
Источник: verification/test-3.cjs; 28 поведенческих сценариев пройдены.
Запросы курсов и время в тестах моделируются; пользовательское хранилище
и реальные деньги не используются.

1. Первый вход, настройка, первая хотелка; пустое количество не становится 1.
2. Перенос прежних данных с точной резервной копией, сохранением планов и Архива.
3. Редактирование, отмена, копирование и удаление текущей позиции.
4. Сохранение нескольких позиций одной карточкой.
5. Сохранение нескольких позиций отдельными карточками.
6. Сохранение напрямую в Большой план без лишних карточек в Избранном.
7. Отмена способа сохранения и ввода имени не стирает текущий список.
8. Разделение с копиями сохраняет валюты, количество и существующие планы.
9. Разделение с заменой общей карточки также не меняет существующие планы.
10. Внутренние позиции прямого плана сохраняются при пересборке и редактируются.
11. Поиск вложенных названий, регистр, е/ё, фильтры и переход из Архива обратно.
12. Выбор/снятие карточек, объединение от двух, отмена и уход из раздела.
13. Обработчики навигации: нажатие, движение с фиксацией, удержание.
14. Обработчики барабана: быстрый свайп, удержание, движение и фиксация.
15. Ошибка хранилища не стирает текущий список и исходные данные.
16. Ошибка одной валюты не оставляет частично обновлённые данные; есть подтверждение.
17. Заставка при запуске, коротком возврате и возврате через 15 минут.
18. Выключенные анимация и реплики не блокируют настройки и кнопку назад.
19. Уникальные HTML-id, локальные ссылки, безопасный вывод пользовательских названий.
20. Новый ритм только для новых карточек; сохранённые и Архив не меняются.
21. Новый ритм для всех активных; Архив не меняется, текущие позиции сохраняются.
22. Общее обновление валют: текущие данные, карточки, планы; Архив по выбору.
23. Сортировка не меняет исходный массив, неизвестный курс отправляет запись в конец.
24. Все шесть единиц рабочего времени и четыре периода исходной суммы.
25. Нет «Удалить всё» в пустых списках; диалоги не вызывают клавиатуру автофокусом.
26. Закрытие поиска сохраняет ввод формы; Escape снимает блокировку слоёв.
27. Повреждённые данные и ошибка резервной копии не приводят к их перезаписи.
28. Системное ограничение анимации и заставка при новой загрузке.

Дополнительно: проверен синтаксис всех шести JS-файлов, CSS разобран парсером,
проверено наличие локальных ресурсов, целостность ZIP и совпадение его файлов
с проверенными исходниками.

КАК ПОВТОРИТЬ (ДЛЯ РАЗРАБОТЧИКА)

В папке verification: npm install, затем npm test; нужен Node.js 24+.
Для установки сайта эти команды НЕ нужны. В архиве нет node_modules.

ОГРАНИЧЕНИЯ ПРОВЕРКИ

jsdom моделирует DOM и события, но не рисует интерфейс и не является Safari.
Не проверялись на физическом iPhone: экранная клавиатура, safe-area,
визуальная точность радиусов/теней, системное распознавание жестов,
поведение установленного на экран «Домой» веб-приложения.
Доступность валютного API в сети/регионе пользователя не проверялась;
проверены успешные и ошибочные ответы модели сервиса.
Автопубликация в GitHub не выполнялась.
