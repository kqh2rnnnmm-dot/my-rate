MY RATE — ПАТЧ 2.3

Что исправлено:
- Барабан работает одним непрерывным жестом: удержание, движение вверх-вниз, отпускание и фиксация.
- Внутренние строки барабана больше не пересоздаются под пальцем.
- Убрана служебная надпись «Крути» и дополнительное нажатие после выбора.
- Соседние варианты появляются только во время активного вращения.
- Барабан единиц результата скрыт до добавления первой хотелки.
- Подсказка об объединении показывается для одной карточки, активная кнопка появляется только после выбора двух и более.

Как обновить сайт на GitHub:
1. Открой репозиторий my-rate.
2. Загрузи все шесть файлов из этого архива: index.html, styles.css, config.js, app.js, calculator.js, storage.js.
3. Если GitHub спросит о замене файлов с такими же названиями — подтверди замену.
4. README.txt загружать необязательно.
5. Старые файлы заранее удалять не нужно.

После обновления открой сайт и обнови страницу. Старые сохранённые карточки и проекты будут перенесены автоматически, насколько позволяет их прежний формат.
