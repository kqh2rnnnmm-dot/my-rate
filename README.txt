MYRATE — ПАТЧ 3.1.1

УСТАНОВКА
1. Распакуй MyRate_3_1_1.zip.
2. В репозитории my-rate открой Add file → Upload files.
3. Загрузи одновременно восемь файлов в прежнюю папку сайта:
index.html, styles.css, config.js, app.js, calculator.js, storage.js,
collections.js, interface.js.
4. Нажми Commit changes и дождись публикации GitHub Pages.
5. Открой сайт по прежнему адресу и обнови страницу.

Старые файлы заранее удалять не нужно. Не очищай данные сайта.
ZIP в репозиторий загружать не нужно. README, CHECKS и verification —
только инструкция и проверки, для работы сайта не нужны.

ИЗМЕНЕНИЯ
— Старое обучение с плавающими выделениями отключено.
— Семь историй с демонстрационными примерами, свайпами в обе стороны,
кнопками «Назад»/«Дальше», прогрессом и крестиком. Автоперелистывания нет.
— Вход: «Как это работает?» на первом экране и в FAQ,
«Пройти знакомство заново» в настройках.
— Истории не создают карточки, не меняют рабочий ритм и не очищают черновик.
— На первом экране отдельно предлагается настроить свою математику.
— Поиск получил непрозрачный фон; исходный экран скрывается до закрытия.
— Единые радиусы для карточек/окон, полей/вложенных элементов и капсул.
— Три точки в карточках — цельные иконки, не переносимый текст.
— Декоративные ручки свайпа удалены.
— На длинном экране возможен однократный мягкий сдвиг содержимого,
если после появления информации пользователь не взаимодействует с экраном.
При касании/прокрутке, вводе, открытых окнах и уменьшении движения он отменяется.

ПРОВЕРКА НА IPHONE
Открой настройки → «Пройти знакомство заново».
Пролистай семь историй, попробуй назад, свайп и закрытие.
Проверь поиск с открытой клавиатурой из разных разделов.
Убедись, что прежние карточки и планы сохранены.

Автоматические проверки пройдены, но отрисовка и клавиатура физического
iPhone в этой среде не проверялись. Подробности в CHECKS.txt.
