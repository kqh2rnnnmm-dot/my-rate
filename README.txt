MY RATE v0.1-alpha — BUILD 1

Что работает:
- стартовый экран;
- ввод дохода и рабочего графика;
- расчет личного часового курса;
- ввод названия вещи и цены;
- перевод цены в часы работы и рабочие дни;
- доля месячного дохода;
- локальное сохранение профиля в браузере;
- мобильная адаптация.

Как проверить локально:
1. Открой папку проекта.
2. Дважды нажми index.html.
3. Сайт откроется в браузере.

Для GitHub Pages достаточно загрузить всю структуру папки в репозиторий и включить Pages.
