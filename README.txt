MY RATE — PATCH v0.1.4
Исправления по семи приложенным файлам. 11 сентября 2026.

КАК ОБНОВИТЬ САЙТ
1. Скачай архив и распакуй его на компьютере.
2. Открой на GitHub тот репозиторий, из которого сейчас опубликован My Rate.
3. На вкладке Code нажми Add file → Upload files.
4. Перетащи из распакованного архива index.html и три папки: css, js, data.
   Именно их, а не весь архив и не внешнюю папку MyRate-patch.
5. Внизу нажми Commit changes.
6. Дождись завершения публикации во вкладке Actions и открой прежнюю ссылку сайта.
   На компьютере обнови страницу сочетанием Ctrl+F5.

ЧТО ЗАМЕНИТЬ / ДОБАВИТЬ

ЗАМЕНИТЬ, если существуют, или ДОБАВИТЬ:
  css/styles.css

README.txt, CHECK-REPORT.md и папка verification предназначены для информации
и повторной проверки; загружать их на сайт не нужно.

БЫСТРАЯ ПРОВЕРКА ПОСЛЕ ЗАГРУЗКИ
1. Доход 150000 ₽ в месяц, 5 дней в неделю, 8 часов в день.
2. Добавь тестовую вещь: цена 60000 ₽, количество 1.
3. Должно получиться около 69,3 ч; при выборе рабочих дней — 8,67.
4. Сохрани расчёт. Открой «Сохранённые расчёты» и проверь запись.
5. Вернись к текущему расчёту и обнови страницу: позиция должна остаться.
6. На телефоне проверь прокрутку барабанов пальцем: выбранная единица и итог
   должны меняться вместе. Это действие не удалось проверить на реальном iPhone.

СОХРАНЁННЫЕ ДАННЫЕ
Расчёты v0.1.3 и проекты читаются по прежним ключам браузера.
Профиль ранней версии из отдельных файлов переносится, если он корректен.
Для сохранения прежней истории используй тот же адрес сайта, тот же браузер
и тот же профиль браузера. На другом устройстве история автоматически не появится.
Не очищай данные сайта. Новый архив сам по себе не содержит твою историю.
Если обнаружены старые записи v0.1.1 без снимка дохода и курса, программа
сохраняет оригинал и показывает предупреждение: для точного переноса нужен
отдельный разбор старого формата. Повреждённые списки не перезаписываются.
