MY RATE — ПАТЧ 3.1

КАК ОБНОВИТЬ ЧЕРЕЗ GITHUB — БЕЗ ТЕРМИНАЛА

1. Распакуй MyRate_3_1.zip.
2. Открой существующий репозиторий my-rate и папку с файлами сайта.
3. Нажми Add file → Upload files.
4. Загрузи ВСЕ ВОСЕМЬ файлов одновременно в ту же папку, где сейчас index.html:
   index.html, styles.css, config.js, app.js, calculator.js, storage.js,
   collections.js и interface.js.
5. Нажми Commit changes и дождись завершения публикации GitHub Pages.
6. Открой сайт по прежнему адресу и обнови страницу.

Заранее удалять старые файлы не нужно. Не загружай ZIP вместо распакованных
файлов и не помещай восемь файлов во вложенную папку.
README.txt, CHECKS.txt и verification нужны только для инструкции и проверок.

СОХРАННОСТЬ ДАННЫХ

Карточки и планы находятся на устройстве, а не в репозитории GitHub.
Обновляй существующий сайт по тому же адресу и не очищай его данные.
Формат хранилища совместим с 3.0: карточки, планы и Архив сохраняются.

ЧТО ИСПРАВЛЕНО В 3.1

— Активные основные кнопки снова синие. Неактивные остаются серыми,
  вторичные — белыми с тёмной рамкой, опасные действия — красными.
— Убрано задвоение заголовка и рывок верхней части экрана после заставки.
  Основной заголовок появляется только после завершения переноса заставки.
— Новый пользователь проходит знакомство по настоящему сценарию:
  настраивает рабочий ритм, создаёт и сохраняет первую карточку, затем вторую,
  выбирает обе, собирает Большой план и возвращается в «Хочу — могу?».
— Во время знакомства нужная область подсвечивается, а подсказка объясняет,
  что заполнить или нажать. Этап сохраняется, поэтому случайная перезагрузка
  не начинает весь путь заново.
— Существующих пользователей знакомство не прерывает. Запустить его вручную
  можно через шестерёнку → «Пройти знакомство заново». Учебные карточки и план
  при этом настоящие; перед повторным запуском приложение об этом предупреждает.
— Редактор карточки учитывает видимую область при открытой клавиатуре:
  активное поле прокручивается к центру, содержимое окна остаётся доступным,
  нижняя панель действий закреплена внутри редактора.
— Отступы, высоты полей, радиусы карточек, заголовки и панели действий приведены
  к общей сетке. Кнопки над «Избранным» больше не уезжают вправо.

Сохранены все возможности 3.0: барабаны, изменение текущих позиций, три способа
сохранения нескольких позиций, разделение карточки, поиск, Архив, Большие планы,
обновление курсов, пересчёт по новому рабочему ритму, заставка и подпись PROBA.

КАК ПРОВЕРИТЬ ЗНАКОМСТВО

На устройстве с уже настроенным MyRate открой шестерёнку и нажми
«Пройти знакомство заново». Совсем новый пользователь увидит знакомство сам.
Пропустить его можно соответствующей кнопкой — существующие данные не удаляются.

ЧТО ПРОВЕРИТЬ НА IPHONE

1. После заставки заголовок появляется один раз, без задвоения и рывка.
2. Основные активные кнопки синие на всех экранах.
3. Полный сценарий знакомства: ритм → две карточки → Большой план → возврат.
4. В редакторе карточки последовательно открыть название, цену и количество:
   каждое активное поле должно оставаться над клавиатурой.
5. Кнопки над списками выровнены и не выходят за общую сетку.
6. Прежние карточки, планы и Архив остались на месте.

Автоматические проверки перечислены в CHECKS.txt. Они не заменяют проверку
отрисовки, клавиатуры и жестов на настоящем iPhone/Safari.
