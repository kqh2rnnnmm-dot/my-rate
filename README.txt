MY RATE — ПАТЧ 3.0

КАК ОБНОВИТЬ ЧЕРЕЗ GITHUB — БЕЗ ТЕРМИНАЛА

1. Распакуй MyRate_3_0.zip.
2. Открой существующий репозиторий my-rate и папку с файлами сайта.
3. Нажми Add file → Upload files.
4. Загрузи ВСЕ ВОСЕМЬ файлов одновременно в ту же папку, где сейчас index.html:
   index.html, styles.css, config.js, app.js, calculator.js, storage.js,
   collections.js и interface.js.
   Шесть заменят прежние версии, два последних — новые.
5. Нажми Commit changes. Дождись завершения публикации GitHub Pages.
6. Открой сайт по прежнему адресу и обнови страницу.

Заранее удалять старые файлы не нужно. Не загружай ZIP вместо распакованных
файлов и не помещай восемь файлов во вложенную папку.
README.txt, CHECKS.txt и verification нужны для инструкции и проверок;
для работы сайта они необязательны. Новый сервер, платный API и установка
зависимостей для сайта не нужны.

СОХРАННОСТЬ ДАННЫХ

Карточки и планы находятся на устройстве, а не в репозитории GitHub.
Обновляй существующий сайт по тому же адресу: другой адрес не увидит прежние данные.
Не очищай данные сайта для установки патча: это удалит сохранённое на устройстве.

Перед переходом на формат 3.0 приложение сохраняет исходную копию прежних данных
в локальном хранилище. При ошибке чтения или записи резервной копии оно сообщает
об этом и не перезаписывает оригинал. Копия не защищает от очистки данных сайта.

Текущие НЕСОХРАНЁННЫЕ позиции и незавершённая форма, как и раньше, живут
в открытом приложении. Переходы между разделами их не стирают, но полная
перезагрузка страницы может их потерять. Сохраняй в «Избранное» или «Большие планы».

ЧТО НОВОГО

— Первый вход объясняет смысл My Rate и ведёт к настройке исходных значений.
  При настроенном ритме этот путь повторять не нужно. Изменить ритм можно
  видимой кнопкой «Подкрутить мой ритм» и через настройки.
— Барабаны получили графическую демонстрацию жеста и краткую инструкцию.
  Быстрый свайп — для страницы, удержание и движение — для барабана.
  После отпускания выбор фиксируется сам. Названия единиц времени сохранены.
— Каждую текущую позицию можно изменить, скопировать или убрать через три точки.
— При нескольких текущих позициях «Куда это всё?» предлагает одну карточку,
  отдельные карточки или сразу Большой план. Отмена сохраняет текущий список.
— Общую карточку можно разделить на отдельные копии либо заменить отдельными
  карточками. Ранее собранные планы от этого не меняются.
— Позиции плана, созданного напрямую, редактируются и без копий в «Избранном».
— Локальный поиск по названиям карточек, позиций и планов, включая Архив.
  Есть фильтры; поиск начинается с двух символов. Запрос не отправляется на сервер.
— Плавающая нижняя капсула с отдельной круглой кнопкой поиска.
  Нажатие открывает раздел; движение вдоль панели выбирает его при отпускании.
  Удержание без движения открывает действия раздела. Те же действия доступны
  кнопкой над списком. Добавлены сортировка и обновление курсов раздела.
— Упорядочены отступы, поля, кнопки и плоские иконки. Нижняя панель скрывается
  при вводе. Учтены безопасные отступы экрана и видимая область при клавиатуре.
— Выбор карточки снимается повторным нажатием. Общая «Отмена» находится внизу.
  Смена раздела сбрасывает выбор. «Объединить» появляется от двух карточек.
— Обновление курсов и массовый пересчёт требуют подтверждения. Ошибка получения
  одной валюты не оставляет частично обновлённые данные. Новый ритм можно применить
  только к новым карточкам или ко всем активным; Архив при этом не меняется.
  В общее обновление курсов Архив включается отдельным выбором.
— Подсказки и FAQ дополнены новыми механиками и уточнением о валютном сервисе.

Сохранены заставка 2.7, «Магия пересчёта», реплики, Архив и подпись PROBA.
Полная заставка появляется при новом запуске/перезагрузке страницы;
после короткого возврата из фона её нет, после 15 минут — сокращённая.

ЧТО ПРОВЕРИТЬ НА СВОЁМ IPHONE

1. Прежние карточки, планы и Архив на месте.
2. Первый вход — отдельно в частной вкладке Safari, не очищая данные сайта.
3. Барабаны: быстрый свайп страницы, затем удержание, движение вверх-вниз
   без отрыва пальца, отпускание и фиксация.
4. Нажатие, движение и долгое удержание нижней панели.
5. Клавиатура в форме, поиске и редакторе не перекрывает нужные кнопки.
6. Две тестовые позиции: изменение, три способа сохранения, разделение
   общей карточки, поиск по названию вложенной позиции плана.
7. Заставка, возврат из фона и отключение анимации/реплик.

Автоматические проверки перечислены в CHECKS.txt. Они не заменяют проверку
отрисовки, клавиатуры и жестов на настоящем iPhone/Safari.
